# MikuMikuToon

**Toon shading for MMD models, in Blender.**

Import a `.pmx` / `.pmd` model into Blender, press one button, and it turns into the clean
flat-shaded look MMD has — not by stacking a filter on top, but by **rebuilding a toon setup
from the model's own material data**.

---

## What it does

| | |
|---|---|
| **One-click toon** | A single button reads the model's materials, applies the toon setup and generates the outline. No hand-tuning material by material |
| **Reads materials natively** | It reads mmd_tools' material data directly (base colour / sphere / sub-texture / transparency / outline) with **no destructive conversion** — the spangles, metal, rhinestones and gradients the author drew are all still there |
| **Builds its own toon nodes** | The shading nodes, the outline and the bloom are all generated by the add-on, and it **depends on no third-party add-on's node groups or asset files**. The nodes are assembled inside the `MikuMikuToonData/MikuMikuToonShading.blend` that ships with the add-on — you can open that file in Blender and edit it by hand, and if it is missing the add-on rebuilds the nodes on the spot |
| **Adjustable outline** | One number for the thickness; the colour can follow each material's own `edge_color`, or be unified across the whole model |
| **Eye shadow** | One click turns the "目影" material into semi-transparent black |
| **Bloom** | A compositor effect driven by the emission pass, so it works with no lighting; the strength is **measured per model**, so a dark-coloured character does not come out dimmer than the rest |
| **Credit watermark** | The author credit is forcibly burned into renders and cannot be turned off; an edited copy turns itself into an "unauthorized modified copy" |
| **It does not lock up your file** | mmd_tools' material data is never rewritten, and you can stop using the add-on at any time |

## Installation

### Requirements

* **Blender 4.5 or newer** (it can be enabled from 4.3; 4.5+ is the full experience)
* The open-source add-on **[mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/)** — importing MMD models relies on it

### Install the add-on

1. Download `MikuMikuToon.zip` (attached to the **Releases** page on GitHub)
2. In Blender: `Edit > Preferences > Add-ons`
3. The dropdown arrow `v` in the top right → **Install from Disk**
4. Pick the zip → tick the checkbox next to **MikuMikuToon**
5. **Restart Blender**

> **Why restart?** A running Blender does not reload add-on code. Without a restart the newly
> installed version may not take effect, or the panel may simply not appear.

### Install mmd_tools

If you don't have it yet:

`Edit > Preferences > Get Extensions` → search for `mmd_tools` → install and enable

### Check that it worked

Press `N` to open the sidebar — there is a **Toon** tab. Open it and you have the panel.

**If the panel doesn't show up:**
1. In Preferences, **untick "MikuMikuToon" and tick it again**
2. If that doesn't help, restart Blender
3. Read the lines starting with `[MikuMikuToon]` in the system console — the add-on prints
   what is missing and what to do about it
4. You can also run `bpy.ops.mikumikutoon.selfcheck()` in the Python console for a full report

## How to use it

1. Import the model with mmd_tools
2. Select the model (object mode; you can also switch to "replace a single material" to
   process only the selected material)
3. `N` → the **Toon** tab → press **One-click toon**
4. Tweak whatever you like: outline thickness / colour / eye shadow under "other settings",
   and the glow section holds "add glow" plus per-game presets

Before rendering, leave the **colour management** view transform on "Standard" — one-click toon
switches it for you, because AgX / Filmic washes out the toon colours and flattens the shading.

## What it does not do

* **It does not import models** — that is mmd_tools' job
* **It does not modify the model** — only materials and render settings are touched; not a single
  vertex of geometry is moved
* **It contains no third-party code or assets** — a paid add-on's node groups may not be
  redistributed, so this one builds everything itself
