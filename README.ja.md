# MikuMikuToon

**MMD モデルを Blender でトゥーン（セルルック）にするアドオン。**

`.pmx` / `.pmd` モデルを Blender に読み込み、ボタンをひとつ押すだけで MMD らしい
すっきりしたフラットな質感になります —— フィルターを重ねるのではなく、
**モデル自身のマテリアルデータからトゥーン構成を組み直します**。

---

## できること

| | |
|---|---|
| **ワンクリック・トゥーン** | ボタンひとつでマテリアルを読み取り、トゥーンを適用し、輪郭線を生成。マテリアルごとに手作業で調整する必要はありません |
| **マテリアルのネイティブ読み込み** | mmd_tools のマテリアルデータ（基色・球面・サブテクスチャ・透明度・輪郭線）を直接読み込み、**破壊的な変換は行いません** —— 作者が描いたスパンコール、金属、ラインストーン、グラデーションはそのまま残ります |
| **トゥーンノードは自作** | シェーディングノード・輪郭線・ブルームはすべてアドオンが生成し、**サードパーティ製アドオンのノードグループやアセットファイルには依存しません**。ノードはアドオン同梱の `MikuMikuToonData/MikuMikuToonShading.blend` に組み立てられています —— このファイルは Blender で直接開いて手で編集でき、無い場合はその場で組み直します |
| **輪郭線を調整可能** | 太さは数値ひとつ。色はマテリアルごとの `edge_color` に従わせることも、モデル全体で統一することもできます |
| **目影** | 「目影」マテリアルをワンクリックで半透明の黒に |
| **ブルーム** | コンポジタ効果で、自発光チャンネルで駆動するためライト無しでも効きます。強度は**モデルごとに実測して自動決定**するので、暗い色のキャラクターが他より暗くなりません |
| **署名の透かし** | レンダリング時に作者の署名を強制的に焼き込みます（オフ不可）。改変されたコピーは自ら「未授权修改版」になります |
| **ファイルを縛りません** | mmd_tools のマテリアルデータは書き換えません。いつでもアドオンを使うのをやめられます |

## インストール

### 必要なもの

* **Blender 4.5 以降**（4.3 から有効化できますが、4.5 以降がフル機能です）
* オープンソースのアドオン **[mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/)** —— MMD モデルの読み込みに必要です

### アドオンのインストール

1. `MikuMikuToon.zip` をダウンロード（GitHub の **Releases** ページの添付）
2. Blender で：`編集 > プリファレンス > アドオン`
3. 右上のドロップダウン矢印 `v` → **ディスクからインストール**
4. zip を選択 → **MikuMikuToon** の左のチェックボックスを入れます
5. **Blender を再起動**

> **なぜ再起動が必要か**：起動中の Blender はアドオンのコードを再読み込みしません。
> 再起動しないと、新しく入れた版が反映されなかったり、パネルがそもそも出なかったりします。

### mmd_tools のインストール

まだ入っていない場合：

`編集 > プリファレンス > 拡張機能を取得` → `mmd_tools` を検索 → インストールして有効化

### 入ったかどうかの確認

`N` でサイドバーを開くと、タブに **Toon** があります。開けばアドオンのパネルです。

**パネルが見当たらない場合：**
1. プリファレンスで「MikuMikuToon」の**チェックを外して、もう一度入れる**
2. それでも駄目なら Blender を再起動
3. システムコンソールの `[MikuMikuToon]` で始まる行を見てください ——
   何が足りないか、どうすればよいかをアドオン自身が出力します
4. Python コンソールで `bpy.ops.mikumikutoon.selfcheck()` を実行すると、完全なレポートが出ます

## 使い方

1. mmd_tools でモデルをインポート
2. モデルを選択（オブジェクトモード。選択したマテリアルだけを処理する
   「単一マテリアルを置換」に切り替えることもできます）
3. `N` → **Toon** タブ → **ワンクリック・トゥーン** を押す
4. 好みで調整：「その他の設定」の輪郭線の太さ / 色 / 目影、グローのブロックには
   グローの追加とゲーム別プリセットがあります

レンダリング前に**カラーマネジメント**のビュートランスフォームは「Standard」のままに
してください —— ワンクリック・トゥーンが自動で切り替えます。
AgX / Filmic はトゥーンの色を洗い流し、明暗を平坦にしてしまうためです。

## やらないこと

* **モデルのインポートはしません** —— それは mmd_tools の仕事です
* **モデル自体を変更しません** —— 触るのはマテリアルとレンダリング設定だけで、
  ジオメトリは頂点ひとつ動かしません
* **サードパーティのコードやアセットを含みません** —— 有料アドオンのノードグループは
  再配布できないため、このアドオンはすべて自作しています
