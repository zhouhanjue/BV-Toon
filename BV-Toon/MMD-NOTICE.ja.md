# MMD のマナーと署名

BV-Toon は**シェーディング用のツール**です。MMD のモデル・テクスチャ・モーション・表情
データは一切含まず、素材は**ご自身が正規に入手した**モデルに由来します。本アドオンで制作した
作品を公開する際は、**素材作者の利用規約に従ってください**。

## 推奨する署名形式

```
モデル：<作者名>（<配布ページのリンク>）
モーション：<作者名>（<リンク>）      ← モーションを使った場合のみ
レンダリング：BVToon / @BVan
使用ツール：BV-Toon
```
最小構成：`モデル：<作者名>（<リンク>）` + `レンダリング：BVToon / @BVan`

## よくある条項（必ず作者の記載に従う）

| 条項 | 意味 |
|---|---|
| 商用利用の禁止 | 収益化される内容への使用不可（投げ銭・広告・有料会員など） |
| 再配布の禁止 | モデルファイルの転送不可（**改変版も不可**） |
| R-18 / 暴力表現の禁止 | 成人向け・過激な内容への使用不可 |
| 改変後の再配布の禁止 | 改変は自由、改変版の公開は不可 |
| 作者名とリンクの明記 | 作品公開時の署名 —— ほぼすべてのモデルに存在 |
| 特定用途の禁止 | 作品や CP を限定する作者もいる |

**規約に「許可」と書かれていないことは、不可と考えるのが安全です**（特に再配布）。

## よくある誤解

* ❌「マテリアルを変えたから自分のモデル」—— 改変しても著作権は変わりません。
  **改変版はさらに配布できません**
* ❌「画像を上げるだけなら配布ではない」—— 画像は署名と用途制限の遵守が必要です。
  **モデルファイルを同梱して配るのは配布です**
* ❌「アドオンがモデルを持っている」—— BV-Toon は**モデルデータを含みません**。
  お手元のファイルを読むだけです
