# BV-Toon 1.7.2

> MMD 一键卡渲 · 泛光在所有模型上终于一样亮 · 「添加泛光」改成**先测量再定档** ·
> 测不出来会直说，绝不假装测过（完整性校验 / 水印三态 / 损毁画面 / 强制署名与 1.7.1 完全一致）

## 安装

1. 下载 `BV-Toon-1.7.2.zip`（Release 附件）
2. Blender：`编辑 > 偏好设置 > 附加组件 > v > 从磁盘安装`
3. 勾上 **BV-Toon** → 选中 MMD 模型 → `N` → 「**Toon**」标签 → **一键卡渲**

需要 Blender 4.5+ 与开源插件 [mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/)。

> **本版只动泛光。** 1.7.1 的完整性校验、水印三态、损毁画面、强制署名，以及「只给脸加腮红」那一整套
> 逻辑**一行都没改** —— 正常状态的输出照旧带 `渲染 BVToon / @BVan` 署名。清单打进 zip；从源码目录
> **手工拷贝**安装的副本仍显示「未验证副本」，唯一恢复正路还是跑 `python tools\install_bv_toon.py`。

## 症状：泛光不一致，深色角色几乎没有

* 作者的原话：「泛光不一致 —— 胡桃 等角色明显比 奥黛塔 弱；把所有角色都提到 奥黛塔 的水平。」
* 视觉上最极端的说法就是「**胡桃 根本没有泛光**」，而 奥黛塔 那圈光晕很足
* 这不是观感问题，是**可以测出来的**：同一机位、同一设置下，两者的剪影外亮度差 **7 倍**

## 根因：整条泛光链路都由「绝对亮度」驱动（640×853、同一机位、EEVEE 实测）

泛光的来源是渲染的 **Emit 通道**（卡渲着色器本身就是全自发光），再加上**超过阈值 0.95 的贴图部件**，
再加一层「**外发光**」—— 它只在 Emit 的 `max(RGB)` **超过 0.60** 的地方才点火。于是**衣服越暗，
产出的光越少**，全都是绝对量在说话：

| 模型 | 角色平均亮度（不发光时） | 角色身上增加的量 | 剪影外那一圈增加的量 |
|---|---|---|---|
| 奥黛塔（白皮肤 / 白衣） | 0.735 | +0.0497 | +0.160 |
| 芙宁娜 | 0.586 | +0.0075 | +0.029 |
| 胡桃（深色衣服） | 0.421 | +0.0060 | +0.017 |
| 初音ミク | 0.964 | +0.0099 | +0.271 |

奥黛塔 比 胡桃 亮 **7 倍** —— 所以「胡桃 根本没有泛光」这个说法一点都不夸张。

* **试过、被否掉的做法**：第一版想按材质的平均基色 × `亮度` 猜一个逐模型增益。它不管用 ——
  材质平均值**预测不了画面上有多少面积是亮的**：按它对 胡桃 只推出 **1.44×** 的增益，
  而实测她需要**大约 9×**。

## 本版重点：点「添加泛光」时先测量，不再猜

* 「添加泛光」现在会**先渲染两帧 192×192**（泛光强度 0 与当前强度），然后只看
  **「剪影外那圈光」**：泛光关掉时是黑的、泛光打开时被点亮的、且**距剪影不超过 2 px** 的像素
* 看完就**闭环**：这一圈比目标暗，就把强度乘上去**再测一次**，最多 **3 轮**
  （「泛光关」那帧复用，所以成本是 **1 + N 张极小的渲染**）
* **目标值 0.16** —— 这正是 奥黛塔 在大家都满意的那套设置下测出来的值
* 自动值夹在 **[0.03, 2.50]** 之间，而且是**只升不降**：本来就比目标亮的角色（初音ミク，0.271）
  **原样不动** —— 需求是「别让深色角色更暗」，不是「把亮的压下去」

| 环节 | 内容 |
|---|---|
| **测量帧** | 192×192 × 2（强度 0 / 当前强度），「泛光关」那帧在闭环里复用 |
| **被测像素** | 泛光关为黑、泛光开被点亮、且距剪影 ≤ **2 px** 的像素（「剪影外那圈光」） |
| **目标** | **0.16** |
| **闭环** | 暗于目标 ⇒ 乘强度重测，最多 **3 轮** |
| **取值** | 夹在 **[0.03, 2.50]**，**只升不降** |

## 本版重点：标定口径（这些数字为什么必须这么定）

* 测量带必须是**画面的固定比例**（192 px 下的 2 px ≈ 宽度的 **1%**），因为**光晕半径本身
  就是画面的百分比** —— 两者必须一起缩放
* 反面例子：在 **96 px** 上用 **3 px** 的带测量，采到的是**紧贴剪影的亮芯**，响应被高估
  —— 胡桃 在那里读 **0.265**，而全分辨率的真值是 **0.166**
* 只测一次也不够：泛光在 **1.0** 处会**削顶**（奥黛塔 的每单位强度响应在强度 0.10 时是 **1.49**，
  在 1.2 时只剩 **0.43**），所以必须闭环，不能靠一次线性外推

## 其它改动（1.7.2）

* **测量期间的现场保护**：临时把长边分辨率设成 **192 px**（保持长宽比）、关掉渲染水印，并
  **临时摘掉强制署名的 `render_pre` 处理器**（白色水印文字会污染测量），**用完一定装回去**
  —— 审计现在会断言测量之后该处理器**仍然挂载**
* 渲染设置全部还原，临时 PNG 写在临时目录并**删除**
* **测不出来就直说**：场景没有摄像机、画面里没有被框住的东西、或找到的圈像素**少于 12 个**时，
  插件会在操作报告里**明确说明**（同时存进场景的 `bv_glow_note`），并保留旧的默认强度 **0.10**，
  **不会假装测到了什么**
* 泛光组新增输入 **`增益`**（gain，默认 **1.0**）：对基于 Emit 的泛光源做手动倍率，作用在
  **外发光闸门之前** —— 这样闸门本身也变成相对模型的量。它是**手拧的旋钮，不自动设定**
* 新增验证工具：`tools\check_glow_uniform.py`（逐模型 导入 → 一键卡渲 → 添加泛光 → 关/开渲染，
  然后断言外圈亮度 **≥ 0.10 且 ≤ 0.45**、强制署名处理器熬过了测量、归一化后的各模型
  **互相在 1.6× 以内**；当前 `failures=0`）、探针 `_scratch\probe_glow_models.py`，
  以及 `tools\audit_bv_toon.py` 里**新增的 6 项泛光检查**（现在 **70 通过 / 2 项已知假失败**
  —— `remove_glow` 与 `set_eye_shadow` 返回 CANCELLED 是正常现象）
* 对比图：`_glow_demo\`，逐模型成对存放 `<name>-0-noglow.png` / `<name>-1-glow.png`

## 实测与复现验证

口径：**同一机位**，两家版本都**按自动强度**渲染。

| 模型 | 修前外圈 | 修后外圈 | 角色身上（修前 → 修后） |
|---|---|---|---|
| 奥黛塔 | 0.160 | **0.152** | — |
| 胡桃 | 0.017 | **0.144** | **+0.0060 → +0.083** |
| 芙宁娜 | 0.029 | **0.142** | **+0.0075 → +0.061** |
| 初音ミク | 0.271 | **0.271**（只升不降，原样不动） | — |

* 奥黛塔 / 胡桃 / 芙宁娜 三者的外圈**互相在 1.07× 以内**（修前是 **7×**）；初音ミク 按只升不降
  的规则**保持 0.271 不变**

```
& 'C:\Program Files\XF Blender 4.5\blender.exe' -b --factory-startup --python tools\check_glow_uniform.py -- dist\BV-Toon-1.7.2.zip _glow_demo <模型.pmx 或 .pmd …>
python tools\package_bv_toon.py --verify
```

第一条逐模型跑完整测量（成对截图与断言落在 `_glow_demo\`），第二条核对打进 zip 的那份清单。

## 工具坑：测量会把强制署名处理器摘下来（必须装回去）

* 测量要在**没有水印文字**的画面上做，所以测量期间会**临时卸载**强制署名的 `render_pre` 处理器
* 风险很实在：万一忘了装回去，**之后每一次渲染都会静默地少掉 `渲染 BVToon / @BVan` 署名**，
  而且不会有任何报错
* 因此**无论如何都会装回去**，并且 `tools\audit_bv_toon.py` 会**断言测量之后处理器仍然挂载**

## 升级与兼容（1.7.1 → 1.7.2）

* 泛光节点组**多了一个输入** ⇒ 升级后请**先删掉泛光再加一次**（或者直接再按一次「添加泛光」
  —— 它本身就是先删再加）
* 强度是**从当前机位 / 姿势测出来的** ⇒ 改了机位或换了模型之后，想要重新测量就再点一次
  「添加泛光」
* zip 是 `dist\BV-Toon-1.7.2.zip`，安装走 `编辑 > 偏好设置 > 附加组件 > 从磁盘安装`；
  需要 Blender 4.5+ 与 mmd_tools
* 完整性清单**打进 zip**；从源码**手工拷贝**安装的副本会显示「未验证副本」水印，
  唯一的官方恢复办法是跑 `python tools\install_bv_toon.py`

## 已知未做

* 目标值 **0.16** 是在**一个参考模型**（奥黛塔）的**默认设置**下标定的，换一套设置就可能偏
* 自动强度是**场景级**的值（它活在合成器里泛光组节点上）：同一个场景里放多个亮度差很大的角色时，
  测出来的是**整个机位画面**的值 —— 需要逐角色的值就**拆成多个场景**
* 1.7.1 里列出的那几项（材质名特殊规则、副纹理高亮、认脸覆盖面）与本版无关，仍然未做
