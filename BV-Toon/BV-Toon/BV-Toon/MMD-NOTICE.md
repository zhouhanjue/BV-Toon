# MMD 使用规范与署名

BV-Toon 只是一个**着色工具**。它不包含、也不分发任何 MMD 模型、贴图、动作或表情数据 ——
所有素材都来自**你自己合法获得**的模型。所以用本插件出图、并对外发布时，
**请遵守素材各自作者的使用规范（利用規約）**，这一点比插件本身的许可更重要。

## 发布作品时的署名格式

请把**模型 / 动作 / 配布元**的出处写清楚，并注明使用的是本插件。推荐格式：

```
模型：<模型作者名>（<配布页面链接>）
动作：<动作作者名>（<链接>）          ← 用了动作才写
渲染：BVan
使用工具：BV-Toon（https://github.com/<你的用户名>/BV-Toon）
```

最小可用版本（至少这几行）：

```
模型：<作者名>（<链接>）
渲染：BVan
```

## 请务必先读模型自带的规范

每个 MMD 模型的 `readme.txt` / 配布页面通常都会写清楚。**常见条款**（以模型作者实际写的为准）：

| 条款 | 含义 |
|---|---|
| 禁止商用 | 不能用于盈利内容（含打赏、广告、付费会员） |
| 禁止再配布 | 不能把模型文件转发给别人（**改过也不行**） |
| 禁止 R-18 / 暴力表现 | 不能用于成人或过激内容 |
| 禁止改変后再配布 | 允许改造，但改造版不能发出去 |
| 必须标注作者名与链接 | 发布作品时要署名 —— **这条几乎每个模型都有** |
| 禁止用于特定作品/CP | 有些作者会限制用途 |

**如果规范里没写"允许"的事，通常就当作不允许**（尤其是再配布）。

## 常见误区

* ❌ 「我改过材质了，所以模型算我的」—— 改造不改变模型的著作权；**改过的版本更不能分发**。
* ❌ 「我只发了渲染图，不算配布模型」—— 发图没问题，但要署名并遵守用途限制；**把模型文件附在图包里发才是配布**。
* ❌ 「插件能读模型，所以插件里带着模型」—— BV-Toon **不带任何模型数据**，它只读你本机的文件。

## 关于本仓库里的演示图

本仓库**不含**任何用第三方模型渲染的图片（有意排除）。你若要往仓库或 Release 里放演示图，
请先确认模型作者的规范允许公开，并按上面的格式署名（`渲染：BVan`）。
