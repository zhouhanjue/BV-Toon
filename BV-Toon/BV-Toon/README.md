# BV-Toon

**中文** ｜ [English](README.en.md) ｜ [日本語](README.ja.md)

> MMD 模型一键卡渲 · 原生读取材质 · 边缘预览 · 目影 · 腮红 · 泛光 · 强制署名水印

**当前版本：1.7.2**

**BV-Toon 是独立编写的 Blender 插件**：代码、节点图、资产全部自写，不含任何第三方插件的代码或资源。
着色节点组装在自带的 `BVToonData/BVToonShading.blend` 里，可以直接用 Blender 打开手改；缺少该资产时会自动回退到现场生成。

> 设计上参考了 MMD 卡渲的通行做法，并受同类 Blender 插件的公开行为启发。运行需要开源插件 [mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/)。本项目与任何第三方插件不存在代码或资源上的关系。

## 它做什么

| 功能 | 说明 |
|---|---|
| **一键卡渲** | 一个按钮：套卡渲预设 → 生成 MMD 边缘预览 |
| **原生读取材质** | 直接读 mmd_tools 的 `mmd_material`（基色/球面/副纹理/透明度），**不做破坏性转换**，球面层的闪片与光泽不会丢 |
| **卡渲预设** | 一键卡渲 / 冷调 / 夜色暖，参数就是 `bv_shading.py` 里那张表，随便改 |
| **泛光** | 合成器效果：**自发光（Emit）驱动 + 剪影外发光**，不打光也有效果，亮背景不跟着糊；**强度按模型实测自动定**（深色角色不会比别人暗）；可一键摘除 |
| **腮红 / 目影** | 腮红**只加在脸上**：先认出脸部材质，再优先拿**模型自带的腮红贴图（`照れ` 之类）当遮罩**（作者画的形状），没有就退回**几何脸颊圈**（`腮红保底 + 脸颊圈`，不看明暗）；目影把「目影」材质设成半透明黑 |
| **强制署名水印** | 渲染前强制烧录 `渲染 BVToon / @BVan`（85% 透明、无底框）；改过的副本会变成「未授权修改版」。处理器带 `persistent` 标记，并在每次启用/画面板时补挂 —— 新建或打开文件之后**依然强制** |
| **材质树保持干净** | 卡渲接管后材质树里的非卡渲节点会被清理，只留 `bv_*` 与输出（避免两套节点打架）。mmd_tools 的 `mmd_material` 数据本身不改写，但**没有「一键还原成基本材质」按钮** |

## 完整性校验（哈希防盗）

打包时会生成 `BVToonData/integrity.json`（7 个顶层 `.py` + 卡渲资产的 SHA-256），随 zip 一起发出。
插件**加载时**、**每次画面板**、**每次渲染前**各核对一遍：

| 状态 | 什么时候 | 水印 |
|---|---|---|
| 正常 | 清单在，文件都对得上 | `渲染 BVToon / @BVan`（85% 透明白字，面板可改） |
| 未授权修改版 | 清单在，但有文件被改 / 丢失 / 多出 | `未授权修改版 / UNAUTHORIZED MODIFIED COPY`（不透明红字 + 黑底） |
| 未验证副本 | 没有清单，或者清单读不懂 | `未验证副本 / UNVERIFIED COPY`（不透明红字 + 黑底） |

### 校验不过：画面一定会被损毁（没有档位可选）

**没有开关、没有下拉框** —— 面板上只有一行说明：`损毁：被改或未验证都损毁（唯一档位，无选项）`。
规则只有一条：

* 校验**通过** → 画面照常
* 校验**不过**（被改 / 未验证）→ 画面被**像素化 + 压色阶 + 去饱和压暗**，一眼就是废图

损毁走合成器（`bv_damage.py`），所以静帧、动画、视口渲染**都**生效；恢复正常（重算清单）后
节点会被摘掉、接线还原，不留垃圾。

* **为什么不给选项**：改过的副本不该还能出能用的图，不留放宽的余地
* **代价（如实说）**：因为"未验证"也算不过，所以**从源码目录直接拷进 `addons` 的副本
  （没有清单）也会被损毁**；恢复正常只有一条正路：跑一次 `tools/install_bv_toon.py` 重算清单
* **这不是加密，也不打算是**：懂行的人可以把清单一起重算，也可以停用插件。
  它挡的是「随手改个名就说是自己写的」，以及让改过的副本**自己出不了能用的图**。
* **与许可的关系**：GPL v3 允许修改与再分发 —— 这里动的只是**这个副本自己渲染出来的画面**，
  不限制任何人改代码、再分发或商用；LICENSE §7 附加条款第 2 条本来就要求「修改版必须以合理方式
  标明与原始版本不同」，水印与损毁都是那条要求的实现。
* 清单覆盖范围是顶层 `*.py` 与 `BVToonData/BVToonShading.blend`；文档与 `LICENSE` 不在范围内。

## 腮红（只给脸）

点「添加腮红（只给脸）」时：

1. **认出"脸"**：材质名里的 `颜/顔/脸/face/フェイス…` → 网格名 → 底色贴图名（唯一）→
   头部几何（MMD 标准骨 `頭`/`首` 划出的区域里面积最大的那块）→ 唯一的肤色材质（`肌/skin`）。
   一种都没命中就**报警 + 列出材质名**，绝不猜、也绝不"干脆全加"；**连几何都是猜的**、
   而且猜到的材质**面数 < 128**（多半是眼睛/嘴之类的零件）时，面板会弹红字让你按「脸=当前材质」自己指
2. **优先用模型自带的腮红贴图**（`照れ` / `blush` / `チーク`…）当遮罩 —— 那是作者自己画的腮红形状。
   注意这种贴图是**用 alpha 画图案**的（实测 `照れ.png` 2048²、98% 全透明、RGB 几乎是均匀浅粉，
   拿亮度当遮罩完全没用），所以插件把它接到卡渲组的 **`腮红贴图`** 输入上，并用一个
   `Map Range` 把淡 alpha 规整成明确遮罩（0.15 以下当没有、0.50 以上当满）
3. 模型没有这种贴图 → 退回**渲染器自带的腮红遮罩**：`腮红保底 + (1 − 腮红保底) × 脸颊圈`。
   **它不看明暗、只看几何** —— 早先按"亮度阈值"做的两版（绝对亮度、相对亮度）在好几个模型上
   实测恒等于 0，脸上一点腮红都没有；现在整块脸材质上一定有 `腮红保底`（默认 0.35）的浓度，
   两颊再由**脸颊圈**加到最浓（球心吸在脸材质的真实顶点上、半径 = 脸半宽的 42%）
4. 其余材质上的腮红一律**清零**；认出的结果与用的机制显示在面板上
   （`脸材质：颜` / `腮红：着色器腮红，位置=脸颊（…）`）

跨模型验收（9 个模型，640×853，同机位，逐像素断言"变化只在头部"）：
初音ミク 661 / MEIKO 5547 / 巡音ルカ 1775 / 胡桃 1203 / 芙宁娜 549 / 雷电 444 / 沃雅妮莎 633 /
蕾米埃尔 200 像素。自带 `照れ` 贴图的模型走第 2 条（作者画的形状），例如 奥黛塔 是
"两个明确的脸颊红点"（192 像素、跨 8 行）而不是"整脸一片潮红"（2096 像素、跨 63 行）。

面板模式＝`替换单个【材质】`时用当前激活的材质槽（认不出脸的模型的手动口子）。

## 泛光（强度按模型实测，不看角色深浅）

泛光整条链吃的都是**绝对亮度**（源是渲染的 Emit 通道 + 画面超阈值的部分，外发光还有一道
"自发光 > 门槛"的开关），所以深色角色天然比浅色角色吃得少 —— 实测同一套参数下，
奥黛塔剪影外那圈光 **+0.160**，胡桃只有 **+0.017**（差 7 倍，观感就是"胡桃没泛光"）。

现在点「添加泛光」时**先量再定**：

1. 渲两张 **192×192** 小图（强度 0 / 当前值），看**剪影外那圈光**被提亮多少
   （"关着是黑、开着才亮、且贴着剪影 2 像素以内"的像素求平均）
2. 不够亮就按比例加，**闭环**最多重来 3 轮，逼近目标 **0.16**（= 奥黛塔在大家都认可的
   设置下量到的值）；自动值夹在 `[0.03, 2.50]`
3. **只往上调**：本来就比 0.16 亮的角色保持原样（不会把亮的压暗）
4. 量不出来（没相机 / 相机没框住 / 剪影外少于 12 个像素）会**如实写在报告里**，
   强度保持默认 `0.10`，不假装量过

实测结果：剪影外那圈光 奥黛塔 **0.152** / 胡桃 **0.144** / 芙宁娜 **0.142**（相差 1.07 倍）。

合成器里的 `BVToon_Glow` 组节点可以随时手调：**强度 / 阈值 / 大小 / 外发光 / 增益**。
`增益` 是手动微调用的乘数（乘在自发光那一支上，位置在外发光门槛之前 —— 所以它同时也把
"多亮才算亮部"变成相对这个模型的）。

> 量的是**当前相机看到的画面**：换了机位或换了模型，想重新量就再点一次「添加泛光」。

## 依赖

- **Blender 4.5 或更新**（泛光用 Eevee Next 的 Emit 通道；3.6+ 可用但泛光受限）
- **[mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/)**（开源 MMD 导入器）——
  读取 MMD 材质、导入模型、边缘预览都要它

不需要其它任何插件。

## 安装

1. `编辑 > 偏好设置 > 附加组件 > 右上角 v > 从磁盘安装` → 选 `BV-Toon-1.7.2.zip`
2. 在列表里勾上 **BV-Toon**
3. 选中 MMD 模型 → `N` → 「Toon」标签 → **一键卡渲**

从源码目录手工拷贝安装也可以，但那样没有完整性清单，水印会显示「未验证副本」——
想要正常署名就用 Release 里的 zip，或者自己在副本目录里跑一次
`python tools/install_bv_toon.py --target <那个目录>`。

## 目录结构

| 文件 | 作用 |
|---|---|
| `__init__.py` | bl_info、面板、操作符、渲染前强制水印 |
| `bv_util.py` | 读 mmd_tools 的 MMD 材质数据、自建 UV 组、球面/副纹理层 |
| `bv_shading.py` | 卡渲节点组（Python 现场生成）+ 预设表 |
| `bv_materials.py` | 套用 / 清理节点 / 腮红 / 目影 / 描边 / 环境色 |
| `bv_glow.py` | 泛光（自发光驱动 + 剪影外发光 + 按模型实测自动定强度） |
| `bv_integrity.py` | 完整性校验（哈希清单的生成与核对，三态判定） |
| `BVToonData/BVToonShading.blend` | 卡渲节点组资产（75 节点 / 31 接口，可手改） |
| `BVToonData/integrity.json` | 打包/安装时生成的哈希清单（不是手写的） |
