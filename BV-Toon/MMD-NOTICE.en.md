# MMD Etiquette & Attribution

BV-Toon is only a **shading tool**: it ships no MMD models, textures, motions or expressions.
All assets come from models **you obtained legitimately**. When publishing work made with this
add-on, **follow the terms of use (利用規約) of each asset's author**.

## Recommended credit format

```
Model: <author> (<distribution page link>)
Motion: <author> (<link>)             <- only if a motion was used
Render: BVToon / @BVan
Tools: BV-Toon
```
Minimum: `Model: <author> (<link>)` + `Render: BVToon / @BVan`

## Typical terms (always read the author's own text)

| Term | Meaning |
|---|---|
| No commercial use | Not for monetised content (tips, ads, paid membership) |
| No redistribution | Do not pass the model files on (**not even modified**) |
| No R-18 / violent use | Not for adult or extreme content |
| No redistributing edits | Editing is fine; publishing the edit is not |
| Credit required | Author name and link must be stated — almost universal |
| Usage restrictions | Some authors restrict pairings or specific works |

**If the terms do not explicitly allow something, assume it is not allowed** (especially redistribution).

## Common misunderstandings

* ❌ "I edited the material, so the model is mine" — editing does not change copyright, and a
  **modified version is even less distributable**
* ❌ "Posting an image is not distribution" — images need credit and must respect usage limits;
  **shipping the model files inside an image pack is distribution**
* ❌ "The add-on carries the model" — BV-Toon **contains no model data**; it only reads your files
