# BV-Toon 1.8.1

> **描边颜色可调**（面板「统一描边颜色」）· 描边认 MMD 的 `edge_flag` 与 **瞳 / 目 / 眉** ·
> **其他游戏转来的模型不再发暗**（纯灰底色不再当染色）· 面板不再"少几个选项"（`draw()` 只读）·
> 泛光性能 · 完整性校验 / 三态水印 / 损毁画面 / 强制署名不变

## 安装

1. 下载 `BV-Toon-1.8.1.zip`（Release 附件）
2. Blender：`编辑 > 偏好设置 > 附加组件 > v > 从磁盘安装`
3. 勾上 **BV-Toon** → 选中 MMD 模型 → `N` → 「**Toon**」标签 → **一键卡渲**

需要 Blender 4.5+ 与开源插件 [mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/)。

> 装完**请重启 Blender**：运行中的 Blender 不会重新加载插件代码，否则面板显示的还是旧版。

## 这一版有什么

### 1. 描边颜色可调（新）

面板「其他设置」里一行「**统一描边颜色**」+ 取色器：

* **不勾（默认）**：每个材质用它自己的 MMD `edge_color`（模型作者画好的那种）
* **勾上**：整个模型统一用你选的颜色。旁边「应用」同时重套**粗细 + 颜色**，不用重跑一键卡渲

`mmd_edge.*` 的材质里颜色后面跟着一个 `Gamma 2.2`，所以统一颜色时做了反向补偿 ——
**选什么显示什么**（实测选 `(0.6,0,0)` → 描边像素 `(0.32,0.03,0.03)`）。
标了「不画描边」的材质（眼、嘴、目影）不会被染色 —— 它们本来就不长壳。

### 2. 描边认 MMD 的「画不画」

* `edge_flag = 0` 的材质不再靠一层透明材质挡着，而是**几何上直接不长壳**；
* 名字里带 **瞳 / 目 / 眉**（任意一个字）的材质**一律不画描边**，哪怕模型标着"画"
  （参照模型 `Vesna.pmx`：目/瞳/眉 壳权重 0.01083 → 0.00000）。

### 3. 其他游戏转来的模型不再发暗（重要）

明日方舟：终末地、原神、崩铁这类**转换包**经常把**每个材质的底色统一写成 `0.8` 灰**。
MMD 的渲染是 ``贴图 × (底色 × 光照 + 环境色)`` —— **纯灰的底色不是颜色，是"受光程度"**；
而卡渲是全自发光（不打光），再乘 0.8 只会平白压暗 20%。现在会**跳过纯灰的底色**：

* 有色偏 → 当染色（初音ミク 那种纯色材质靠的就是它，修复保留）
* 纯灰且不暗（≥ 0.6）→ 不乘
* 纯灰但明显压暗（< 0.6）→ 保留（作者故意做暗件）

实测 `D:\da\Liino`（终末地 Liino）：皮肤明度 **0.654 → 0.718**（贴图自身是 0.737，即 97%），
和包内官方海报（0.775）基本一致。**19 个模型批量体检**：无报错、无发黑、无丢几何，
每个模型有 6~29 个灰底材质受此影响 —— 是系统性问题，不只终末地。

### 4. 面板不再"少几个选项"（bug 修复）

以前的 `draw()` 里会"如果属性不存在就现场补一个" —— 而 Blender 有些上下文**禁止写 ID**，
于是抛 `AttributeError: Writing to ID classes in this context is not allowed`，
**异常之后的按钮全都画不出来**（表现就是"面板上没有那个选项"）。
现在面板要用的属性全部是**注册过的真属性**（永远存在），`draw()` 只读不写。
审计里加了两道检查（静态 + 用"写就抛"的假场景真画一遍），以后不会再犯。

### 5. 泛光性能

开泛光的**总**开销 **+2.72 秒 → +0.99 秒**（4K 实测）：点「添加泛光」时把合成器切到 GPU
（4.5 默认 CPU，用你原来的设置会在摘掉泛光时还回去）＋ Glare 质量 HIGH → MEDIUM ＋
可选的 `GLOW_CANVAS`（默认关）。剪影外那圈光**不变**。

### 6. 署名改成强制（选项已取消）

面板上原来的三个可选项（**烧录署名**勾选框 / **署名文字** / **不透明度**）全部去掉，
只留一行说明 `署名：强制烧录，不可关闭（选项已取消）`：

* **一律烧录** —— 一键卡渲与渲染前处理器都不再判断开关；
* **文字固定** —— 正常态永远是 `渲染 BVToon / @BVan`；被改过/未验证的副本由完整性给警告文字
  （「未授权修改版」/「未验证副本」）；
* **不透明度固定** 0.15（85% 透明）。
* 审计加 4 条把"关不掉"钉死：把老开关全设成关、文字改成别的、透明度设 0 → 走一遍强制署名，
  画面**仍然**是默认署名。

### 7. 游戏泛光预设（折叠菜单，三个游戏）

「泛光」区块下面有折叠起来的「**游戏泛光预设**」，一键把泛光调成那个游戏的样子
（**点「添加泛光」之后才出现，点「移除泛光」后隐藏**）：

| 按钮 | 强度 | 阈值 | 大小 | 外发光 | 增益 |
|---|---|---|---|---|---|
| 终末地泛光 | 1.10 | 0.55 | 9 | 0.24 | 1 |
| 原神泛光 | 0.08 | 1.20 | 9 | 0.24 | 1 |
| 绝区零泛光 | 0.10 | 1.30 | 9 | 0.24 | 1 |

实测（胡桃、暗底、整幅平均亮度）：自带自动强度 0.277 ｜ 终末地 **0.336**（很猛，亮部会爆白）｜
原神 0.277 ｜ 绝区零 0.277。嫌强嫌弱就改节点上的「强度 / 阈值」。

### 8. 面板重排：四个区块

```
[BV-Toon 一键卡渲]   模式 / 一键卡渲 / 提示
[泛光]              添加·移除 +（有泛光时）折叠的游戏泛光预设   ← 独立小区块，底色深一档
其它设置            描边粗细 + 应用 ／ 设置目影 ／ 统一描边颜色 + 取色器
介绍                署名（强制）／ 使用条款（三语）／ 损毁（唯一档位，无选项）
```

## 已知 / 注意

* 老场景（本版之前卡渲过的）请重跑一次**一键卡渲**，或按面板「应用」，才会用上新的描边处理。
* 模型包自己缺贴图（PMX 指到不存在的文件）时，那一块退回材质底色，不会变成洋红/全白。
* 5.2 的模糊节点没有 `size_x/size_y` 属性（尺寸改到插座上了），外发光那层的模糊半径没设上 ——
  所以 5.2 的泛光比 4.5 少一层外发光（已知，未改）。
