# BV-Toon 1.4.0

> MMD 模型一键卡渲 · 原生读取材质 · 渐变贴图驱动明暗 · 边缘预览 · 目影 · 腮红 · 泛光

这一版把「看起来像 MMD 原生」往前推了一大步，并修掉了几个让画面**发灰、发花、发深**的问题。

## 安装

1. 下载 `BV-Toon-1.4.0.zip`（Release 附件）
2. Blender：`编辑 > 偏好设置 > 附加组件 > v > 从磁盘安装`
3. 勾上 **BV-Toon** → 选中 MMD 模型 → `N` → 「**Toon**」标签 → **一键卡渲**

需要 Blender 4.5+ 与开源插件 [mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/)。

## 本版重点

### 🔧 修掉的问题

* **泛光绿色重影** —— Blender 4.5/5.x 的 Glare 节点把选项改成了**输入插座**，枚举也变成
  首字母大写（`Bloom` 而非 `BLOOM`）。旧代码用属性赋值 + 静默 `try/except`，**一个参数都没设上**，
  节点一直跑默认的 `Streaks`/`Ghosts` → 画面出现彩色重影。现在按插座名设置，**失败会打印**。
* **宝石 / 闪片 / 金属消失** —— 之前为了治"衣服油腻"，把球面层强度一刀压到 0.30，
  但 MMD 的球面贴图有两种语义：**加算（mode 2）= 闪片、宝石、金属、目光**（效果本体，必须保留）；
  **乘算（mode 1）= 布料上的柔和球面**（压它才是"去油腻"）。现在按模式分开：加算 **1.0**、乘算 **0.30**。
* **衣服颜色过深** —— 底色链里有个「反差」阶段是往 **`底色²`（平方后的暗版）** 混，
  深色布料被压成死黑。默认改为不混（`反差 = 0`）。
* **渐变贴图不生效**（1.3.0 引入的回归）—— 白名单清理把渐变查表链的 6 个辅助节点也删了
  （它们名字是 Blender 自动生成的），现在这些节点统一带 `bv_toon_` 前缀。

### ✨ 新增与变化

* **一键卡渲** = 卡渲 + MMD 边缘预览；「设置目影」拆成独立按钮
* **描边**：用材质自带的 `edge_color`；面板「描边粗细」+「应用」可调（绝对值，默认 **0.08** = mmd_tools 原值）
* **一键卡渲自动把色彩管理切到「标准」** —— AgX/Filmic 会把卡渲的饱和色洗淡、把明暗压平
* **MMD 渐变贴图（toon ramp）驱动明暗** —— 按 MMD 的查表方式 **U = 0.5、V = 受光程度**，
  采样材质自带的 toon 贴图（含共享 `toon01–10`）
* **环境色（ambient）接入暗部色调** —— 只在环境色带颜色信息时生效
* **材质树保持干净** —— 卡渲接管后，非卡渲节点全部清理，只留 `bv_*` 节点与输出
* **阴影默认关闭**（`暗部深浅 = 0`、`分界暖边 = 0`），想要明暗把「暗部深浅」调上去即可
* **独立「Toon」标签页**

### ⚠️ 行为变更（请注意）

* **「还原成基本材质」已移除** —— 原始 MMD 节点现在会被直接清理，想回原始材质请**重新导入模型**
* 卡渲节点组装在自带的 `BVToonData/BVToonShading.blend` 里（可直接打开手改），缺资产时自动回退代码生成

## 工具链（`tools/`）

| 脚本 | 作用 |
|---|---|
| `audit_bv_toon.py` | **一键体检**：注册 / 面板 / 节点白名单 / 渐变链 / 9 个操作符 / 幂等性 / 视图变换 |
| `build_assets.py` | 由代码生成 `BVToonShading.blend` 资产 |
| `render_toon_ab.py` | 同机位 A/B 渲图 + 逐像素对比（透明背景，只统计模型像素） |
| `probe_mask.py` / `probe_toon_math.py` / `probe_toon_axis.py` | 遮罩探针、渐变图数值与轴向检查 |
| `check_toon_ramp.py` / `check_ambient.py` / `check_oneclick.py` | 各项验收脚本 |

```bat
blender -b --python tools\audit_bv_toon.py
```
