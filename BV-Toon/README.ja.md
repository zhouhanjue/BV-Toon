# BV-Toon

> MMD モデルのワンクリック・トゥーンシェーディング · マテリアルのネイティブ読み込み ·
> トゥーンランプによる明暗 · エッジプレビュー · 目影 · チーク · ブルーム · 署名の強制

**独自開発の Blender アドオン**：コード・ノードグラフ・アセットはすべて自作で、
サードパーティ製アドオンのコードやアセットは一切含みません。

## はじめに

1. `BV-Toon-1.5.0.zip`（リリース添付）をダウンロード
2. Blender：`編集 > プリファレンス > アドオン > v > ディスクからインストール`
3. **BV-Toon** を有効化 → MMD モデルを選択 → `N` → 「**Toon**」タブ → **ワンクリック・トゥーン**

Blender 4.5 以降と、オープンソースのアドオン
[mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/) が必要です。

## できること

* **ワンクリック・トゥーン**：トゥーンプリセット + MMD エッジプレビューを一度に
* **MMD マテリアルのネイティブ読み込み**：球面レイヤーは MMD の意味論どおり
  （加算＝スパンコール/宝石/金属、乗算＝布の光沢）
* **トゥーンランプによる明暗**：MMD と同じ参照方法（U = 0.5、V = 受光量）
* **署名の強制**：ワンクリック時と**レンダリング直前**に `渲染 BVToon / @BVan` を焼き込み
  （85% 透明）
* 目影 / チーク / ブルーム / 輪郭線の太さ調整 / ビュートランスフォームを自動で Standard に
