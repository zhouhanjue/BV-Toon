# 更新记录

## 1.1.7 —— MMD 材质还原度大修

这一版把「看起来像 MMD 原生」这件事往前推了一大步，并且修掉了两个让画面发灰/发花的硬 bug。

### 修掉的两个硬 bug

* **泛光出现绿色重影** —— Blender 4.5/5.x 把 Glare 节点的选项从属性改成了**输入插座**，
  而且枚举变成首字母大写（`Bloom` 不是 `BLOOM`）。旧代码用属性赋值 + 静默 `try/except`，
  一个参数都没设上，节点一直跑默认的 `Streaks`/`Ghosts` —— 画面因此出现彩色重影。
  现在按插座名设置，并且**失败会打印**，不再静默吞掉。
* **宝石/闪片/金属全没了** —— 之前为了治"衣服油腻"，我把球面层强度一刀压到 0.30，
  但 MMD 的球面贴图有两种语义：**加算（mode 2）= 闪片、宝石、金属、目光**，
  这一层就是效果本体；**乘算（mode 1）= 布料上的柔和球面**，压它才是"去油腻"该做的。
  现在按模式分开：加算保持 **1.0**，乘算用预设值（**0.30**）。

### 新增

* **MMD 渐变贴图（toon ramp）驱动明暗** —— 按 MMD 的查表方式：**U = 0.5、V = 受光程度**，
  采样材质自带的 toon 贴图（含共享 `toon01–10`）当暗部遮罩；没有该贴图的材质自动退回自建条带。
* **可调描边粗细** —— 面板「描边粗细」+「应用」按钮，改完即时生效，不用重跑一键卡渲。
  默认 **0.08**（= mmd_tools 原值），想加粗直接填 0.2 / 0.4 / 0.8。
* **材质自带描边参数** —— 读 `edge_color` / `edge_weight`，逐材质给 `mmd_edge.<材质名>` 上色。
* **一键卡渲自动把色彩管理切到「标准」** —— AgX/Filmic 会把卡渲的饱和色洗淡、把明暗压平，
  这也是此前"发灰、发淡、偏平"抱怨的一大半原因。
* **环境色（ambient）接入暗部色调** —— 只有环境色**带颜色信息**（三通道不等）时才生效，
  避免被"统一的灰"污染预设的冷色暗部。
* **独立「Toon」标签页** —— 不再和别的插件挤在同一个侧栏标签下。

### 行为调整

* **一键卡渲 = 卡渲 + MMD 边缘预览**；「设置目影」拆成独立按钮（面板「其他设置」里）。
* **默认取消阴影**（`暗部深浅 = 0`、`分界暖边 = 0`）。想要明暗，把「暗部深浅」调上去即可。
* 卡渲节点组装在自带的 `BVToonData/BVToonShading.blend` 里（**可直接打开手改**），
  缺资产时自动回退到代码现场生成。
