# MMD 使用规范与署名

BV-Toon 只是一个**着色工具**：不含任何 MMD 模型、贴图、动作或表情数据，所有素材都来自
**你自己合法获得**的模型。发布用本插件制作的作品时，**请遵守素材作者的使用规范（利用規約）**。

## 推荐署名格式

```
模型：<模型作者名>（<配布页面链接>）
动作：<动作作者名>（<链接>）          ← 用了动作才写
渲染：BVToon / @BVan
使用工具：BV-Toon
```
最小可用：`模型：<作者名>（<链接>）` + `渲染：BVToon / @BVan`

## 常见条款（以模型作者实际写的为准）

| 条款 | 含义 |
|---|---|
| 禁止商用 | 不能用于盈利内容（含打赏、广告、付费会员） |
| 禁止再配布 | 不能转发模型文件（**改过也不行**） |
| 禁止 R-18 / 暴力 | 不能用于成人或过激内容 |
| 禁止改変后再配布 | 允许改造，改造版不能发 |
| 必须标注作者名与链接 | 发布作品要署名 —— 几乎每个模型都有 |
| 禁止特定用途 | 有些作者会限制作品/CP |

**规范没写"允许"的事，通常就当作不允许**（尤其再配布）。

## 常见误区

* ❌「我改过材质，所以模型算我的」—— 改造不改变著作权，**改过的版本更不能分发**
* ❌「只发图不算配布」—— 发图要署名并守用途限制；**把模型文件附在图包里发才是配布**
* ❌「插件带着模型」—— BV-Toon **不含任何模型数据**，只读你本机的文件
