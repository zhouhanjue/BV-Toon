# MikuMikuToon

**给 MMD 模型用的 Blender 卡渲（卡通渲染）插件。**

把 `.pmx` / `.pmd` 模型导进 Blender，点一下按钮，它就变成 MMD 那种干净利落的平涂质感 ——
不是"再叠一层滤镜"，而是**从模型自己的材质数据重新搭一套卡渲**。

---

## 它做什么

| | |
|---|---|
| **一键卡渲** | 一个按钮：读出模型的材质、套上卡渲、生成描边。不用一个个材质手调 |
| **原生读取材质** | 直接读 mmd_tools 的材质数据（底色 / 球面 / 副纹理 / 透明度 / 描边），**不做破坏性转换** —— 作者画的闪片、金属、水钻、渐变都在 |
| **卡渲节点自己搭** | 着色节点、描边、泛光全部由插件生成，**不依赖任何第三方插件的节点组或资源文件**。节点组组装在插件自带的 `MikuMikuToonData/MikuMikuToonShading.blend` 里 —— 那个文件可以直接用 Blender 打开手改，少了它插件会现场重建 |
| **描边可调** | 粗细一个数字，颜色可以逐个材质用模型自带的，也可以整体统一 |
| **目影** | 一键把「目影」材质设成半透明黑 |
| **泛光** | 合成器效果，用自发光通道驱动，不打光也有；强度**按模型自动量**，深色角色不会比别人暗 |
| **署名水印** | 渲染时强制烧上作者署名，不可关闭；被改动过的副本会自己变成「未授权修改版」 |
| **不锁死你的文件** | 不改写 mmd_tools 的材质数据，随时可以不用这个插件 |

## 安装

### 需要什么

* **Blender 4.5 或更新版本**（4.3 起才能启用，4.5+ 才是完整体验）
* 开源插件 **[mmd_tools](https://extensions.blender.org/add-ons/mmd-tools/)** —— 导入 MMD 模型要靠它

### 装插件

1. 下载 `MikuMikuToon.zip`（GitHub 的 **Releases** 页面附件）
2. 打开 Blender：`编辑 > 偏好设置 > 附加组件`
3. 右上角的下拉箭头 `v` → **从磁盘安装**
4. 选那个 zip → 勾上 **MikuMikuToon** 左边的复选框
5. **重启 Blender**

> **为什么要重启**：正在运行的 Blender 不会重新加载插件代码。不重启的话，
> 新装的版本可能不生效，或者面板干脆不出现。

### 装 mmd_tools

如果你还没装：

`编辑 > 偏好设置 > 获取扩展` → 搜 `mmd_tools` → 安装并启用

### 确认装好了

按 `N` 打开侧栏，页签栏里有一个 **Toon**。点开就是插件面板。

**万一没看到面板**：
1. 在偏好设置里把「MikuMikuToon」**取消勾选再重新勾上**
2. 还不行就重启 Blender
3. 看系统控制台里 `[MikuMikuToon]` 开头的行 —— 插件会自己把「缺了什么、怎么办」打出来
4. 也可以在 Python 控制台敲 `bpy.ops.mikumikutoon.selfcheck()`，它会打一份完整自检报告

## 怎么用

1. 用 mmd_tools 把模型导入 Blender
2. 选中模型（物体模式。也可以切到「替换单个【材质】」只处理选中的材质）
3. `N` → **Toon** 标签 → 点 **一键卡渲**
4. 想调就调：「其它设置」里的描边粗细 / 颜色 / 目影，泛光区块里的添加泛光与游戏预设

出图前建议把**色彩管理**的视图变换保持「标准」—— 一键卡渲会自动帮你切过去，
因为 AgX / Filmic 会把卡渲的颜色洗淡、明暗压平。

## 什么不做

* **不导入模型** —— MMD 模型的导入交给 mmd_tools
* **不改模型本身** —— 动的只有材质与渲染设置，几何一个顶点不动
* **不含任何第三方插件的代码或资产** —— 付费插件的节点组不能跟着分发，这个插件自己从零搭
